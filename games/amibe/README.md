# amibe

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install amibe   # dépendances
bin/jumphp run amibe       # jouer sur le bureau
bin/jumphp test amibe      # vérifications + test automatique sans écran
bin/jumphp build amibe     # version navigateur -> dist/web
bin/jumphp serve amibe     # http://localhost:8080
```

Commandes : flèches / WASD pour bouger, Espace pour sauter, Échap pour la pause.
