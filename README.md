# Amibe

Simulation de vie

**Play: https://jumphp.net/amibe**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): retro games in PHP, on the desktop and in the browser.
The game is in `games/amibe/`.

```bash
bin/jumphp install amibe    # dependencies (everything runs in Docker)
bin/jumphp run amibe        # play on the desktop
bin/jumphp test amibe       # checks + a headless demo
```
